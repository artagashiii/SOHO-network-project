# SOHO Network Project

## Description
Small Office / Home Office (SOHO) network designed in Cisco Packet Tracer.

## Features
- Router and switch configuration
- DHCP setup
- Multiple connected devices
- Network connectivity testing

## My Role
This was a team project. I contributed by:
- Reviewing the network setup
- Testing connectivity (ping, basic troubleshooting)
- Understanding and analyzing the configuration

## Technologies
- Cisco Packet Tracer
- TCP/IP
- DHCP

## Notes
Main configuration work was done as part of a collaborative effort.
